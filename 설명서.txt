=============================================
   Forza Wheelspin Tracker - 사용 설명서
=============================================


[ 설치 방법 ]

1. Python 설치
   https://www.python.org/downloads/
   Python 3.10 이상 설치
   ※ 설치 시 "Add Python to PATH" 반드시 체크!

2. Tesseract OCR 설치
   https://github.com/UB-Mannheim/tesseract/wiki
   tesseract-ocr-w64-setup-5.x.x.exe 다운로드 후 설치
   ※ 설치 중 "Additional language data" 에서 Korean(kor) 체크
   ※ 기본 경로 유지 (C:\Program Files\Tesseract-OCR\)

3. 라이브러리 설치
   cmd 열고 아래 명령어 실행:
   pip install pillow pytesseract mss opencv-python pandas openpyxl keyboard

4. 파일 구성 (같은 폴더에 넣기)
   wheelspin_tracker.py  <- 메인 프로그램
   실행.bat              <- 실행 파일
   exclusive_cars.txt    <- 독점 차량 목록 (선택)

5. 실행
   실행.bat 더블클릭


---------------------------------------------
[ 초기 설정 ]

■ 모드 선택
  - 일반  : 일반 휠스핀 (영역 2개: CR, 차량)
  - 슈퍼  : 슈퍼 휠스핀 (영역 6개: 3열 x CR/차량)

■ 캡처 영역 설정 (중요!)
  1. 포르자 호라이즌 실행 후 휠스핀 결과 화면 띄우기
  2. 각 영역 오른쪽 ✥ 버튼 클릭
  3. 트래커 창이 최소화되고 반투명 오버레이가 뜸
  4. 마우스로 읽고 싶은 영역을 드래그해서 선택
  5. 모든 영역 설정 후 [영역 저장] 클릭

  일반 휠스핀 영역:
    CR 영역  : 크레딧 금액이 표시되는 흰색 칸
    차량 영역: 차량명/연도/제조사가 표시되는 흰색 칸
  ※ 두 영역을 같은 위치로 잡아도 됩니다.
    CR 로고(노란 원)를 자동 감지해서 구분합니다.

  슈퍼 휠스핀 영역:
    3열 각각 CR 영역 + 차량 영역 설정 (총 6개)

■ 단축키 설정
  기본값: F9
  단축키 입력칸에서 원하는 키 입력 후 [단축키 저장]
  예: f8, f10, ctrl+shift+w


---------------------------------------------
[ 사용 방법 ]

  1. 게임에서 휠스핀을 돌려 결과 화면이 뜨면
  2. 설정한 단축키(기본: F9) 누르기
  3. 자동으로 화면을 캡처하고 결과를 기록

  하단 "마지막 OCR" 칸에서 인식된 텍스트 확인 가능


---------------------------------------------
[ 독점 차량 알림 ]

원하는 차량이 당첨되면 별표(★)로 강조 표시됩니다.

■ 앱에서 관리
  [★ 독점 차량 관리] 버튼 클릭
  차량명 입력 후 추가 또는 Enter

■ 파일로 관리
  exclusive_cars.txt 를 메모장으로 열어서
  차량명을 한 줄씩 입력:

    Corvette E-Ray
    BRZ
    Trick Truck

  ※ 부분 일치로 검색됩니다.
    "BRZ" 입력시 "2013 SUBARU BRZ" 당첨에 매칭됩니다.
  ※ 앱에서 [파일 새로고침] 버튼 눌러야 적용됩니다.


---------------------------------------------
[ 기록 및 통계 ]

  - 모든 기록은 wheelspin_records.csv 에 자동 저장
  - 상단 통계바: 총 횟수 / 차량 수 / 크레딧 합계
  - [엑셀 내보내기] 버튼으로 .xlsx 파일 저장


---------------------------------------------
[ 에러 로그 ]

  오류 발생 시 wheelspin_error.log 파일에 자동 저장
  [🪲 에러 로그 보기] 버튼으로 앱 안에서 확인 가능


---------------------------------------------
[ 문제 해결 ]

증상                     해결 방법
--------------------     ----------------------------------
프로그램 실행 안됨       cmd에서 직접 실행 후 오류 확인
TesseractNotFound 오류   Tesseract 설치 경로 확인
라이브러리 없음 오류     pip install 명령어로 재설치
OCR이 아무것도 못 읽음   영역 미리보기로 캡처 범위 확인
크레딧/차량 구분 틀림    CR 영역을 크레딧 숫자 칸에 맞게 재설정
단축키 반응 없음         관리자 권한으로 실행 또는 다른 키로 변경


---------------------------------------------
[ 생성되는 파일 목록 ]

wheelspin_records.csv            모든 휠스핀 기록
wheelspin_config.json            캡처 영역, 단축키 설정
exclusive_cars.txt               독점 차량 목록
wheelspin_error.log              에러 로그
wheelspin_YYYYMMDD_HHMMSS.xlsx   엑셀 내보내기 파일
